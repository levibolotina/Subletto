# Subletto — Architecture Reference

> Version: 0.1.0 | Stack: Next.js 14 · Fastify · Prisma · Supabase · Clerk · Stripe · Resend

---

## Repository Layout

```
subletto/
├── apps/
│   ├── web/          # Next.js 14 frontend (App Router)
│   └── api/          # Fastify REST API
├── packages/
│   ├── shared/       # Shared types, constants, pure utils
│   └── db/           # Prisma schema, client singleton, migrations
├── .env.example      # All required environment variables (no secrets)
├── turbo.json        # Turborepo pipeline
├── tsconfig.base.json
└── ARCHITECTURE.md   # This file
```

---

## apps/web

| Concern | Detail |
|---|---|
| Framework | Next.js 14 (App Router) |
| Styling | Tailwind CSS v3 |
| Auth | `@clerk/nextjs` middleware + server components |
| Port | 3000 |

### Directory conventions (`apps/web/src/`)
```
app/
  (auth)/         # Clerk sign-in / sign-up routes
  (marketing)/    # Public-facing pages (home, about, pricing)
  dashboard/      # Authenticated student dashboard
  listings/       # Browse + detail pages
  api/            # Next.js Route Handlers (webhooks, etc.)
components/
  ui/             # Primitive UI components (Button, Card, Input…)
  features/       # Domain-specific composed components
lib/
  clerk.ts        # Clerk server helper re-exports
  stripe.ts       # Stripe client initialisation
  supabase.ts     # Supabase browser/server clients
hooks/            # Custom React hooks
types/            # Web-only type augmentations (re-exports @subletto/shared)
```

### Naming conventions
- Files: `kebab-case.tsx`
- Components: `PascalCase`
- Hooks: `useCamelCase`
- Route groups: `(group-name)` — no URL segment

## apps/api

| Concern | Detail |
|---|---|
| Framework | Fastify v4 |
| Port | 3001 |
| Auth | Clerk JWT verification via `@clerk/fastify` |

### Directory conventions (`apps/api/src/`)
```
routes/
  v1/             # All routes versioned under /v1
    listings.ts
    leases.ts
    users.ts
    webhooks/
      stripe.ts
      clerk.ts
plugins/          # Fastify plugins (auth, cors, helmet)
services/         # Business logic layer (no HTTP concerns)
schemas/          # Zod schemas + Fastify JSON Schema adapters
```

### Naming conventions
- Route files: `kebab-case.ts` matching resource name
- Services: `camelCase` functions, grouped by domain
- Zod schemas: `PascalCaseSchema`

---

## packages/shared

Shared across `web` and `api`. **No runtime dependencies on Node APIs or browser APIs.**

```
src/
  types/      # TypeScript interfaces & enums (DB-agnostic)
  constants/  # Fee rates, domain rules, config values
  utils/      # Pure functions (no side effects)
```

### Rules
- Never import from `@subletto/db` here
- Never use `process.env` here — pass values in as arguments
- Export everything through `src/index.ts`

---

## packages/db

Owns all database concerns.

```
prisma/
  schema.prisma   # Single source of truth for data model
  migrations/     # Auto-generated by `prisma migrate dev`
src/
  index.ts        # PrismaClient singleton + re-exported types
```

### Schema conventions
- Table names: `snake_case` (via `@@map`)
- Model names: `PascalCase`
- ID fields: `cuid()` strings
- Money: stored as **integer cents** (never floats)
- Timestamps: `createdAt` / `updatedAt` on every model

## Environment Variables

See `.env.example` for all required keys grouped by service:

| Group | Purpose |
|---|---|
| `DATABASE_URL` / `DIRECT_URL` | Supabase PostgreSQL (pooled + direct) |
| `SUPABASE_*` | Storage + realtime |
| `CLERK_*` | Authentication + .edu gating |
| `STRIPE_*` | Payment processing + Connect |
| `RESEND_*` | Transactional email |
| `API_*` | Internal web↔api communication |

---

## Data Flow

```
Browser → Next.js (App Router)
           ├── Server Components → @subletto/db (direct Prisma, read-heavy)
           └── Client Components → apps/api (mutations, payment flows)
                                     └── @subletto/db
```

Webhooks (`/api/webhooks/stripe`, `/api/webhooks/clerk`) are handled in Next.js Route Handlers and forward to api services as needed.

## Fee Model

Subletto charges **5% of the first month's rent** as a platform fee, held in Stripe Connect escrow until lease start date. Defined in `packages/shared/src/constants/index.ts` as `SUBLETTO_FEE_PERCENT`.
